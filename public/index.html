Setup

  1. Spotify: developer.spotify.com/dashboard → Create app → add the redirect URI → copy the Client ID (no secret needed, this uses PKCE).
  2. Google: console.cloud.google.com → enable YouTube Data API v3 → OAuth client (Web) → add the redirect URI → copy the Client ID.
  3. Paste the IDs above. They are stored only in this browser's localStorage.
